Muster erkennen: Welche Regel passt?

Es gibt verschiedene Typen von Zuordnungen:

• „Je mehr ..., desto mehr ...“ (Gleichmäßig): Doppelt so viele Artikel kosten auch genau doppelt so viel.

• „Je mehr ..., desto weniger …“ (Verteilen): Doppelt so viele Helfer brauchen nur halb so viel Zeit.

Das Wichtigste zu Zuordnungen (Merke dir!)

1. Was ist eine Zuordnung?

Eine Zuordnung verknüpft zwei Größen miteinander (z. B. Anzahl der Tüten \(\rightarrow\) Preis). Eine Wertetabelle hilft dir, diese Paare übersichtlich aufzuschreiben.

2. Diagramme verstehen

• Steile Linie: Es verändert sich schnell etwas.
• Waagerechte (flache) Linie: Stillstand / Pause (der Wert bleibt gleich).

3. Die zwei Hauptregeln

• „Je mehr …, desto mehr …“ (Doppelte Menge \(\rightarrow\) doppelter Preis).
• „Je mehr …, desto weniger …“ (Doppelt so viele Helfer \(\rightarrow\) halbe Zeit).
